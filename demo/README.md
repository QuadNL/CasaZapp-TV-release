# Demo playlist

Fictional channels to try CasaZapp TV without a subscription of your own. It also has four films and a short series.
The guide and the logos are made up.

Add it in CasaZapp TV as an M3U playlist:

```
https://raw.githubusercontent.com/QuadNL/CasaZapp-TV-release/main/demo/playlist.m3u
```

The guide comes along by itself and it covers three days.
