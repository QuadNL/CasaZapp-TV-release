# Installing the server

CasaZapp TV server runs in Docker. There are two ways to set it up:

- **[Proxmox](server-proxmox.md):** one line in the shell of your Proxmox host makes a container
  with everything in it. Updating is typing `update` in that container.
- **[Docker](server-docker.md):** on anything that runs Docker, such as a NAS, a small Linux box or
  a Raspberry Pi 4 or newer (64-bit). Three commands and it runs.

Then:

- **[After installing](server-after.md):** the first start, finding the server by name, HTTPS
  behind a reverse proxy, casting, updating and backups.
- **[Settings](server-settings.md):** everything you can set, such as your own address or time zone.
